# CodeAlpha - Cloud-Based Bus Pass System

## Project Overview

This project demonstrates a prototype of a cloud-based bus pass booking system developed as part of the CodeAlpha Cloud Computing Internship.

## Key Features

- Online bus pass booking
- Fixed fare validation
- Duplicate booking prevention
- Booking record verification
- High-traffic handling simulation
- Dynamic server provisioning simulation
- Scalability and reliability demonstration
- System testing

## Technologies Used

- Python
- SQLite
- Google Colab

## Project Modules

1. Bus Pass Database
2. Bus Pass Booking
3. Fare Validation
4. Duplicate Booking Prevention
5. Booking Verification
6. Dynamic Server Provisioning Simulation
7. System Testing

## Testing

The system was tested for:

- Valid booking
- Duplicate booking
- Invalid route
- Booking record verification
- Different traffic levels

## Conclusion

This project demonstrates a prototype bus pass booking system with booking validation, duplicate prevention, fixed pricing, database storage, and simulated cloud scalability.
